# Partial coverage suppression proof

Issue: [#215](https://github.com/Binary-Balance/seshat/issues/215).
Local Linux x64 validation, 2026-11-08. This is implementation evidence;
release preparation and platform/package certification remain separate.

The [retained JSON](partial-coverage-suppression.json) records the actual runner
versions, function rows, hint locations and mutation counts/timings. Source byte
offsets refer to the self-contained fixtures generated by
[`coverage-branches.mjs`](../benchmarks/proofs/coverage-branches.mjs).

## Results

Node/Istanbul, Vitest/Istanbul, plain Jest and Jest/Expo each completed with twelve
partial hint comments: an ignored declaration, statement, all statements,
if arm, explicit else arm, implicit else, ternary outcome, logical operand,
a statement before a parenthesized retained initializer, and a statement beside
an otherwise retained branch. The remaining cases ignore an expression statement
containing a function and a direct call outcome containing a retained conditional.
Each route reported twelve `partially-suppressed` containing functions and four
wholly suppressed nested functions. CRAP and its coverage basis remained null for those functions.
Retained coverage included an unexecuted statement and a half-covered ternary;
exclusions did not convert either into full coverage.

Each route rejected a deleted retained statement, a deleted retained branch,
a statement truncated to its first character, and a statement extended to an
unrelated end. Retained statement locations are checked at their full normalized
AST extent before merging setups.

Separate concise conditional and logical arrow fixtures retain their generated
return counters while omitting the expression's branch records on Node, plain
Jest and Jest/Expo. These routes complete with partial status and null CRAP.
Vitest retains the hinted branch records too, so that placement remains unknown
and incomplete. The proof requires that conservative result. A block body with
a statement or branch-outcome hint provides the supported placement.

Function-valued conditional/logical outcomes and a logical group containing a
function also mark their containing functions partial, with null CRAP and
coverage basis, on Node and Jest. Their before-parentheses placement does not
provide usable omitted-counter evidence on Vitest and must remain incomplete.
Deleting retained branches from these fixtures is rejected.

Unsupported enclosing call, array and unary hints, including a call containing
a nested function, remain incomplete even after their branch records are
deleted, both alone and in either setup merge order. A call used directly as a
hinted outcome omits only that outcome counter: its nested conditional still
has two retained outcomes in addition to the outer branch's remaining outcome,
and deleting the nested record fails. The distinction follows Istanbul's
visitor targets and exact normalized branch-outcome spans.

The existing ordinary branch scoring, whole-function/file suppression, c8/v8
counting and Vitest parenthesized-arrow conflict controls also passed.

A real Node check ran one extreme replacement and two comparison mutants;
all three were killed. The partially suppressed function retained positive
statement coverage, null CRAP and checked pseudo-testing. The run attempted six
jobs, required no additional worker baselines, preserved the original source,
and left its scratch directory empty.

Rust checks passed: 191 library tests, three CLI integration tests and twelve
proof-input integration tests. Formatting and Clippy with warnings denied
passed. Focused tests cover wrong/unsupported targets, all statements omitted,
retained ignored counters, wrong branch locations, malformed metadata,
missing retained counters, truncated/extended statement extents, concise returns,
conflicting setup reports in both merge orders, CRAP threshold applicability,
readable output and positive/zero-coverage pseudo-testing while operator mutation jobs remain enabled.

## Reproduce

Install the pinned dependencies described in the proof README, including
`benchmarks`, `benchmarks/proofs`, its Jest/Expo fixture, and `examples/jest`.
Then run from the repository root with the supported Rust toolchain:

```sh
cargo fmt --all --manifest-path crates/seshat/Cargo.toml -- --check
cargo clippy --locked --all-targets --manifest-path crates/seshat/Cargo.toml -- -D warnings
cargo test --locked --manifest-path crates/seshat/Cargo.toml
cargo build --locked --manifest-path crates/seshat/Cargo.toml --bins
SESHAT_PROOF_BINARY=crates/seshat/target/debug/seshat-proofs SESHAT_PROOF_OUTPUT=work/partial-coverage.json node benchmarks/proofs/coverage-branches.mjs
```

Raw generated fixtures and reports remain under ignored
`work/assurance-proofs/coverage-branches-*`. The committed summary has portable
paths. Timings are one local observation, not a performance benchmark.
