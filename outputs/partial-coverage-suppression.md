# Partial coverage suppression proof

Issue: [#215](https://github.com/Binary-Balance/seshat/issues/215).
Local Linux x64 validation, 2026-11-08. This is implementation evidence;
release preparation and platform/package certification remain separate.

The [retained JSON](partial-coverage-suppression.json) records the actual runner
versions, function rows, hint locations and mutation counts/timings. Source byte
offsets refer to the self-contained fixtures generated by
[`coverage-branches.mjs`](../benchmarks/proofs/coverage-branches.mjs).

## Results

Node/Istanbul, Vitest/Istanbul, plain Jest and Jest/Expo each completed with nine
partial hint comments: an ignored declaration, statement, all statements,
if arm, explicit else arm, implicit else, ternary outcome, logical operand,
and a statement beside an otherwise retained branch. Each route reported nine
`partially-suppressed` containing functions and three wholly suppressed nested
functions. CRAP and its coverage basis remained null for those functions.
Retained coverage included an unexecuted statement and a half-covered ternary;
exclusions did not convert either into full coverage.

Each route rejected a deleted retained statement and a deleted retained branch.
The existing ordinary branch scoring, whole-function/file suppression, c8/v8
counting and Vitest parenthesized-arrow conflict controls also passed.

A real Node check ran one extreme replacement and two comparison mutants;
all three were killed. The partially suppressed function retained positive
statement coverage, null CRAP and checked pseudo-testing. The run attempted six
jobs, required no additional worker baselines, preserved the original source,
and left its scratch directory empty.

Rust checks passed: 188 library tests, three CLI integration tests and twelve
proof-input integration tests. Formatting and Clippy with warnings denied
passed. Focused tests cover wrong/unsupported targets, all statements omitted,
retained ignored counters, wrong branch locations, malformed metadata,
missing retained counters, conflicting setup reports in both merge orders,
CRAP threshold applicability, readable output and positive/zero-coverage
pseudo-testing while operator mutation jobs remain enabled.

## Reproduce

Install the pinned dependencies described in the proof README, including
`benchmarks`, `benchmarks/proofs`, its Jest/Expo fixture, and `examples/jest`.
Then run from the repository root with the supported Rust toolchain:

```sh
cargo fmt --all --manifest-path crates/seshat/Cargo.toml -- --check
cargo clippy --locked --all-targets --manifest-path crates/seshat/Cargo.toml -- -D warnings
cargo test --locked --manifest-path crates/seshat/Cargo.toml
cargo build --locked --manifest-path crates/seshat/Cargo.toml --bins
SESHAT_PROOF_BINARY=crates/seshat/target/debug/seshat-proofs SESHAT_PROOF_OUTPUT=work/partial-coverage.json node benchmarks/proofs/coverage-branches.mjs
```

Raw generated fixtures and reports remain under ignored
`work/assurance-proofs/coverage-branches-*`. The committed summary has portable
paths. Timings are one local observation, not a performance benchmark.
