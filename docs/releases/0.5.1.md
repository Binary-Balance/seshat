# Seshat 0.5.1

Published to npm from
[`928d24dde39912984e6828c9830f83594c53d2d9`](https://github.com/Binary-Balance/seshat/commit/928d24dde39912984e6828c9830f83594c53d2d9).
Release evidence is tracked in
[#161](https://github.com/Binary-Balance/seshat/issues/161).

## Runner-reported test timeouts

A test timeout reported by the runner no longer prevents later mutants from
running when the command finishes within its job deadline with complete
evidence, no execution errors and successful cleanup. This includes continuing
from extreme mutation to operator mutation. Timeouts remain unresolved, the
overall mutation score stays withheld and the command exits `2`. Job deadline
timeouts and execution errors still stop scheduling.

JSON retains the existing timeout state and verdict, adds `testTimedOut: true`
to affected setup evidence and reports a separate diagnostic count under schema
version 1. This fixes [#156](https://github.com/Binary-Balance/seshat/issues/156),
merged in [#160](https://github.com/Binary-Balance/seshat/pull/160).
Continuing after a runner-reported timeout may execute more tests than 0.5.0.

## Release packages and checks

The package set is `@binary-balance/seshat@0.5.1` with exact-version native
payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The [platform support matrix](../platform-support.md) is unchanged.

The five native package proofs and Windows runtime proof pass at build head
`cf90ec8e36927868318dbf3ce0ccd7ef6972bb38`. The
[archive and notice audit](0.5.1-audit.md) records all six
exact archives and their source trees. Dependencies, Rust toolchain and notice
bytes match 0.5.0. The macOS proof passed on its second attempt after GitHub's
artifact service failed to retain the first Intel archive.

[Local installation checks](https://github.com/Binary-Balance/seshat/actions/runs/38704856207)
pass on all five hosts, with installed native identities matching the audit.
Fresh review and the
[main-revision publisher dry run](https://github.com/Binary-Balance/seshat/actions/runs/38712037709)
passed before publication approval.

The [publication workflow](https://github.com/Binary-Balance/seshat/actions/runs/38846032627)
published all six packages with the `latest` tag. The first attempt published
the five native packages, then npm rejected the entry package with a duplicate
Sigstore transparency-log entry error. Retrying the unchanged approved inputs
verified and reused the native packages and published the entry package.

Registry downloads match the prepared audit, and all six packages have SLSA
provenance records.
[Registry installation and signature verification](https://github.com/Binary-Balance/seshat/actions/runs/38846289642)
passed on all five supported hosts.

The published [0.5.0 audit](0.5.0-audit.md) is archived separately.
