# Seshat 0.5.1

Release preparation is tracked in
[#161](https://github.com/Binary-Balance/seshat/issues/161).
Publication requires approval of the prepared release.

## Runner-reported test timeouts

A test timeout reported by the runner no longer prevents later mutants from
running when the command finishes within its job deadline with complete
evidence, no execution errors and successful cleanup. This includes continuing
from extreme mutation to operator mutation. Timeouts remain unresolved, the
overall mutation score stays withheld and the command exits `2`. Job deadline
timeouts and execution errors still stop scheduling.

JSON retains the existing timeout state and verdict, adds `testTimedOut: true`
to affected setup evidence and reports a separate diagnostic count under schema
version 1. This fixes [#156](https://github.com/Binary-Balance/seshat/issues/156),
merged in [#160](https://github.com/Binary-Balance/seshat/pull/160).
Continuing after a runner-reported timeout may execute more tests than 0.5.0.

## Release packages and checks

The package set is `@binary-balance/seshat@0.5.1` with exact-version native
payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The [platform support matrix](../platform-support.md) is unchanged.

Native package proofs, the archive and notice audit, five-host local installation,
the publisher dry run and fresh review are pending. The published
