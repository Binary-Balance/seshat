# Seshat 0.12.0

Published on 2026-11-03. Release preparation and publication are tracked in
[#255](https://github.com/Binary-Balance/seshat/issues/255).

## Report whole-function coverage suppressions

Whole-function and whole-file Istanbul `ignore next` and `ignore file` hints
now produce a visible `suppressed` function status with null coverage and CRAP.
Valid suppression alone no longer makes the assessment incomplete. Complexity,
type-safety findings and operator mutations remain available. Pseudo-testing
that requires positive coverage is not applicable for these functions.

Terminal and JSON reports count the hint comments, with per-function counts
and source locations in JSON. Suppression is not a passing coverage or CRAP
value. Missing, malformed or contradictory evidence still makes the assessment
incomplete. Retained function records contradict whole suppression even when
their invocation counts are zero.

This is the whole-function-first slice of
[#215](https://github.com/Binary-Balance/seshat/issues/215), implemented in
[#253](https://github.com/Binary-Balance/seshat/pull/253). Partial statement
and branch hints keep affected functions unknown and the assessment incomplete;
that remaining work stays open. `c8` and `v8` spellings are counted without
claiming they suppress Istanbul instrumentation. Vitest can retain
instrumentation for a hint before parentheses around an arrow; such evidence
stays incomplete. See [coverage suppression hints](../configuration.md#coverage-suppression-hints)
and the [report format](../report-format.md#source-rows-and-function-measurements).

## Mutate statements in async and generator bodies

Statement removal now includes async functions, generators and async generators,
including complete `await`, `yield` and `yield*` expression statements and bare
returns. Removing these statements can skip work, suspension or delegated
iteration and change execution order or generator cleanup. Source replacement
and experimental switching cover the expanded scope.

The statement family is enabled by default, so existing configurations can
generate more mutants, run more jobs and report a different mutation score.
Omit `statement` from an explicit `mutationOperators` array to exclude the
family. Constructors,
statements containing `super()`, implicit scopes, declarations and value-bearing
returns remain outside statement removal. Generators remain outside extreme
mutation.

Each `perOperator` row now reports `eligibleSites` and `excludedSites` before
replacement expansion, including rows with zero planned mutants when every
discovered site is excluded. Disabled families have no rows. These counts
describe static eligibility, independent of coverage or execution.

This resolves [#218](https://github.com/Binary-Balance/seshat/issues/218),
implemented in [#254](https://github.com/Binary-Balance/seshat/pull/254).
The [retained statement evidence](../research/statement-mutations.md) covers
replacement/switching agreement, verdicts, job counts and phase timings.
Its debug timings do not establish release performance.

## Release packages and checks

The package set is `@binary-balance/seshat@0.12.0` with exact-version native
payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The [platform support matrix](../platform-support.md) is unchanged.
The new report status, hint findings and site-count fields extend schema 1.

Both feature PRs passed fresh review and their cross-platform checks. The
published 0.11.0 archive audit is preserved unchanged as
[JSON](0.11.0-audit.json) and [Markdown](0.11.0-audit.md).

The [archive and notice audit](0.12.0-audit.md) records the
six exact archive hashes, native package proofs and Windows runtime evidence
for reviewed build head `a311b2fdac98c844e9af9b4b9889ccb3ff1955d6` in
[PR #256](https://github.com/Binary-Balance/seshat/pull/256). All five native
targets, the Windows runtime proof and the latest-Node compatibility jobs
passed. The release branch's `crates`, `packages` and `packaging` source trees
match the audited build.

All 65 external dependency records, Rust 1.98.1 and runtime notice assets match
0.11.0. The notice file is byte-identical on all five targets and to 0.11.0.

The [release comparison](../research/assessment-scope-verdicts.md) retains
3,038 unchanged shared outcomes across the existing proof scenarios. The
expanded statement fixture adds 300 outcomes across repeated host scenarios,
250 killed and 50 survived, with the intended score changes. Four fault-injection
reports vary by one scheduled job without changing verdicts or completeness.
The retained JSON records exact job counts and phase timings; these single
samples make no performance claim.

[Local archive installation](https://github.com/Binary-Balance/seshat/actions/runs/41569788652)
passed on all five supported hosts at reviewed head
`e82069fa5543a41a353ab27fe54be4eb03513954`, including installed native binary
identity. The fresh audit review found no actionable findings. Release
preparation and its audit merged at
`1b6aa181a198252ed0f9327e20cb954814535c7e` with identical source trees.
The [final publisher dry run](https://github.com/Binary-Balance/seshat/actions/runs/41576981624)
passed at that approved revision.

After explicit maintainer approval, the
[publication workflow](https://github.com/Binary-Balance/seshat/actions/runs/41578026918)
published all six exact archives at the approved revision with the `latest`

[Registry installation and signature verification](https://github.com/Binary-Balance/seshat/actions/runs/41578704671)
