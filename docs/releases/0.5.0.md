# Seshat 0.5.0

Published to npm from
[`fa6406e6fac0fb6be0be07c3d060c039a1b0684b`](https://github.com/Binary-Balance/seshat/commit/fa6406e6fac0fb6be0be07c3d060c039a1b0684b).
Release evidence is tracked in
[#157](https://github.com/Binary-Balance/seshat/issues/157).

## Logical and arithmetic mutations

`check` and `mutate` now enable logical `&&`/`||` and binary arithmetic
`+`/`-`, `*`/`/` swaps alongside comparison mutants. The optional
`mutationOperators` array selects families; `["comparison"]` retains the
0.4.0 operator scope. New mutants participate in the mutation score and can
increase execution cost. Extreme mutation remains separate.

Reports add outcome `kind`, `enabledOperators` and `perOperator` counts and
timings under schema version 1. Logical replacements preserve operand grouping;
experimental switching preserves lazy evaluation and fails explicitly if
a rendered body exceeds 8 MiB.

Binary replacements preserve token boundaries around unary signs, comments,
regular expressions and TypeScript non-null assertions. This prevents an
operator swap from accidentally creating a different operator or a comment.

This implements the logical and arithmetic portion of
[#133](https://github.com/Binary-Balance/seshat/issues/133), merged in
[#155](https://github.com/Binary-Balance/seshat/pull/155). Boolean/negation,
statement removal and optional/nullish operators remain future work. See
[configuration](../configuration.md#mutation-operators) and
[fixture evidence](../research/mutation-operators.md).

## Release packages and checks

The package set is `@binary-balance/seshat@0.5.0` with exact-version
native payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows
x64. Platform limits remain Linux glibc 2.31 for x64 and 2.35 for ARM64, macOS
15, and Windows Server 2022 x64. See the
[platform support matrix](../platform-support.md).

The five native package proofs and Windows runtime proof pass at build head
`60fb88391c31f007467a089286ef88fe156c806b`. The
[archive and notice audit](0.5.0-audit.md) records the six
exact archives and their source trees. Dependencies, Rust toolchain and notice
bytes match 0.4.0.

[Local installation checks](https://github.com/Binary-Balance/seshat/actions/runs/38683382217)
pass on all five hosts, with installed native identities matching the audit.
Fresh review and the
[main-revision publisher dry run](https://github.com/Binary-Balance/seshat/actions/runs/38685013350)
passed before publication approval.

The [publication workflow](https://github.com/Binary-Balance/seshat/actions/runs/38688859117)
published all six packages with the `latest` tag. Registry downloads match the
prepared audit, and all six packages have SLSA provenance records.
[Registry installation and signature verification](https://github.com/Binary-Balance/seshat/actions/runs/38689320314)
passed on all five supported hosts. The published
[0.4.0 audit](0.4.0-audit.md) is archived separately.
