# Seshat 0.8.1

Prepared release, not yet published. Release preparation and publication are
tracked in [#192](https://github.com/Binary-Balance/seshat/issues/192).

## Node coverage locations

The public Node and workspace examples and the shared proof collector now
instrument original TypeScript before Node strips its types. This preserves
multiline statement and branch locations. Previously, source-map remapping could
leave a branch endpoint without a column, making CRAP unknown and the assessment
incomplete. Unimported selected files still receive zero coverage.

The adapters support Node's erasable TypeScript ESM syntax. TSX and syntax that
needs transformation remain outside these example adapters. See the
[Node example](../../examples/node/README.md) and the
[location regression](../../benchmarks/proofs/node-coverage-locations.mjs).
This completes [#166](https://github.com/Binary-Balance/seshat/issues/166).

## Jest and Expo compatibility

Seshat accepts exactly jest-expo 57.0.5 and 57.0.6 with the existing Jest 29.7.0
and Expo dependency set. The proof fixture and public example now pin 57.0.6.
Both the executing preset and the working-directory receipt must report an
accepted version. Future preset versions require separate verification.

Both versions passed the 24-case driver on Linux x64 with Node 24.22.0, retaining
matching mutation verdicts and conservative failure and timeout outcomes. The
[verification report](../../outputs/jest-expo-57.0.6.md) records the evidence and
limits. This completes [#170](https://github.com/Binary-Balance/seshat/issues/170).

## Windows cancellation verdicts

An active child that exits from Ctrl+C or Ctrl+Break now counts as cancelled
when Seshat observes matching host cancellation. Native interrupt exits allow
up to 100 ms for the signal handler to record cancellation. Jobs that completed
normally before the signal and unrelated failures retain their results.

The native Windows proof passed ten Ctrl+C and ten Ctrl+Break attempts with all
40 active jobs cancelled. The change also matches native SIGINT and SIGTERM
exits on Unix. Cancellation continues to withhold the affected score.
This completes [#185](https://github.com/Binary-Balance/seshat/issues/185).

## Coverage report paths

The configuration guide now states that `coverage.report` resolves from the
setup's `cwd`, where the coverage command runs. Report paths cannot contain
`..`, and setups must resolve to distinct report destinations. This corrects
the documentation without changing path resolution.
This completes [#167](https://github.com/Binary-Balance/seshat/issues/167).
