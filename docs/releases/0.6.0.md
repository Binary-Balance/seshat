## Inferred `any`

Report any-typed runtime expression sites per function and setup using the
project's installed TypeScript `>=5.0 <7.0`. The existing compiler metadata
helper creates one checker per setup, retains original UTF-8 source locations
and reports its cost. Unknown, out-of-program and zero findings remain
distinct. Compiler errors, recovery types and enabled `noCheck` produce unknown
findings without blocking an otherwise complete CRAP or mutation assessment.

These are additive report fields under schema version 1. No type-safety
threshold or combined score is added. This completes step 3 of
[#134](https://github.com/Binary-Balance/seshat/issues/134), merged in
[#171](https://github.com/Binary-Balance/seshat/pull/171).
See the [configuration guide](../configuration.md#type-safety-findings) and
[report fields](../report-format.md#type-safety-findings).

Checker work shares the existing setup deadline and adds no mutant jobs. The
synthetic 500-file, 10,000-function fixture added about 2.20 seconds and 282 MiB
over compiler metadata alone. Projects with different compiler inputs can cost
more. The [compatibility and cost evidence](../research/inferred-any.md) records
the supported compiler checks, raw samples and measurement limits.

## Release packages and checks

The package set is `@binary-balance/seshat@0.6.0` with exact-version native
payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The [platform support matrix](../platform-support.md) is unchanged.

The five native package proofs and Windows runtime proof pass at build head
`55904ecd58dc85a3cc7a7a60fefbf127e39cea20`. The
[archive and notice audit](../research/release-notice-audit.md) records all six
exact archives and their source trees. Dependencies, Rust toolchain and notice
bytes match 0.5.1. The published [0.5.1 audit](0.5.1-audit.md) is archived
separately.

Five-host local installation, the exact-archive publisher dry run and final
fresh review are pending.
