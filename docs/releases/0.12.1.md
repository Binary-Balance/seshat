# Seshat 0.12.1

Release preparation is tracked in
[#261](https://github.com/Binary-Balance/seshat/issues/261). Publication is pending.

## Keep parallel jobs from inheriting output pipes

Unix process launches now share a short lock while Rust creates output pipes
and starts the child. Test processes continue to run in parallel. This prevents
another launch from inheriting a temporary pipe writer on macOS, where Rust
sets close-on-exec after creating the pipe. A retained writer could otherwise
make a finished job an execution error and leave later mutants unrun.

The pipe-drain limit, cleanup, cancellation and verdict validation are unchanged.
The [retained reproduction](../research/pipe-drain.md) records the matching
inheritance hazard, before/after probe results and the limits of the diagnosis.
The exact writer owner in the original macOS failure remains unconfirmed.

Resolves [#247](https://github.com/Binary-Balance/seshat/issues/247), implemented
in [#260](https://github.com/Binary-Balance/seshat/pull/260).

## Tolerate startup stalls in collection tests

Four collection tests now allow successful jobs 3 seconds instead of 1 second,
so a one-off host startup stall does not cause a false test failure. Their
timeout and cancellation assertions remain intact. Runtime job limits are
unchanged.

Resolves [#248](https://github.com/Binary-Balance/seshat/issues/248), implemented
in [#259](https://github.com/Binary-Balance/seshat/pull/259).

## Compare native release archives locally

The diagnostics comparison harness reads metadata from the package already
selected for the executable. Native release archives no longer require an
absent entry-package manifest. Combined-archive installation remains covered.

Resolves [#238](https://github.com/Binary-Balance/seshat/issues/238), implemented
in [#258](https://github.com/Binary-Balance/seshat/pull/258).

## Release packages and checks

The package set is `@binary-balance/seshat@0.12.1` with exact-version native
payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The [platform support matrix](../platform-support.md) and report schema are
unchanged. This patch adds no mutation operators or scoring policy.

All three implementation PRs passed fresh review and their configured native
checks before merging. The published 0.12.0 audit is preserved unchanged as
[JSON](0.12.0-audit.json) and [Markdown](0.12.0-audit.md).

The release-specific archive audit, comparison evidence, installation checks
and final publication validation will be recorded here before publication.
