# Seshat 0.9.0

Prepared for publication. Release preparation and verification are tracked in
[#208](https://github.com/Binary-Balance/seshat/issues/208).

## Optional chaining and nullish mutations

The new `optional` family removes one `?.` segment or changes `??` to `||`.
It probes missing nullish guards and defaults that incorrectly treat values
such as zero, false and an empty string as missing. Each eligible token produces
one mutant. The family is enabled by default and adds test jobs; omit `optional`
from `mutationOperators` to retain the previous five-family selection.

Replacement and experimental switching preserve single evaluation, evaluation
order and method receivers. Switching selects complete chains and explicitly
rejects chains used as delete operands or outer call/template targets, where
conditional arms cannot preserve references. Replacement supports those forms.
TypeScript-invalid optional private fields are excluded.

The [transformation contract and evidence](../research/optional-mutations.md)
record 41 semantic cases, 55 active replacement/switching pairs, lifecycle
checks and matched native/launcher costs. Timings describe fixed fixtures under
uncontrolled host load. This completes [#165](https://github.com/Binary-Balance/seshat/issues/165).

## Test-selection fallback notices and exclusions

When selection is unavailable for a whole setup, human output now reports the
reason once, including a rejected command option when identified. JSON records
the same status and reason in `result.setups[].selection`. An available setup
can still use full commands for individual sources or unconfirmed selections.

Selected Vitest commands now preserve both `--exclude <glob>` and
`--exclude=<glob>`. Accepted options are listed in the
[configuration guide](../configuration.md#mutation-execution). Wider coverage
instrumentation, query imports and other unverified attribution still use full
commands. Executed-test identity verification and conservative verdict rules
remain in place. Sixteen matched selection cases retain identical full/selected
verdicts. This completes [#203](https://github.com/Binary-Balance/seshat/issues/203).

## Concurrent captures

Concurrent capture-directory creation retries a colliding name instead of
failing when calls observe the same clock value, including on Windows.
This fixes [#200](https://github.com/Binary-Balance/seshat/issues/200).

## Release packages and checks

The prepared package set is `@binary-balance/seshat@0.9.0` with exact-version
native payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The [platform support matrix](../platform-support.md) is unchanged.

Archive auditing, five-host local installation checks and the final publisher
dry run are pending. npm publication requires approval of the exact prepared
release under the [publication checkpoint](../agents/delivery.md#npm-publication-checkpoint).
The published 0.8.1 audit is preserved unchanged as
[JSON](0.8.1-audit.json) and [Markdown](0.8.1-audit.md).
