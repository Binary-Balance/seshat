# Seshat 0.18.0

Prepared release; not yet published. Preparation and publication are tracked
in [#304](https://github.com/Binary-Balance/seshat/issues/304).

## Vitest browser mode

Assess browser-only TypeScript and TSX with Vitest 5, Playwright and headless
Chromium or Firefox on the five supported hosts. Add the conditional Seshat
plugin to the Vitest config and keep the Seshat reporter in test and coverage
commands. The plugin installs browser evidence hooks; setting `test.runner`
alone does not work in browser mode. See the
[configuration](../configuration.md#vitest-browser-mode) and
[support limits](../runner-compatibility.md#vitest-browser-mode).

One browser instance, default isolation and source replacement are required.
Every mutant runs the full test command. Experimental switching is unsupported.
Other providers, WebKit, headed browsers and custom Playwright launches run
with a visible warning. The adapter uses an undocumented Vitest internal;
changes that prevent evidence collection fail the baseline.

Each job attempt now has a private temporary directory, including compiler
helpers and retries. Cleanup follows process shutdown and removes leftover
browser profiles and artifacts. This also makes temporary caches private to
each attempt for all runners. Cleanup failures stay visible and cannot count
as timeout kills. Browser jobs stalled before a test file starts retry once;
such deadlines remain unresolved even with `countTimeoutsAsKilled`.

The [cost study](../research/vitest-browser-cost.md) supports keeping the
existing cache layout and one-worker default. Measure the consuming project
before adding workers or disabling screenshots.

## Release packages and checks

The package set is `@binary-balance/seshat@0.18.0` with exact-version native
payloads for Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64.
The native platform matrix and Node range are unchanged. Browser diagnostics
and retry evidence are additive; the JSON report retains schema version 1.

The published 0.17.0 audit is preserved unchanged as
[JSON](0.17.0-audit.json) and [Markdown](0.17.0-audit.md).

The [archive and notice audit](../research/release-notice-audit.md) records the
six exact archives built from preparation head
`609cf0e4f3545865afa8c858f09a8cd0f7a7d238` in
[PR #305](https://github.com/Binary-Balance/seshat/pull/305). All five native
package proofs, Windows runtime and latest-supported-Node checks passed.
External dependencies, Rust 1.98.1 and individual runtime notice assets match
0.17.0; combined notice bytes and SHA-256 are identical on all five targets.

The [native comparison](../research/browser-release-verdicts.md) retains 838
report pairs. All 3,333 shared outcomes retain their verdicts and counted-kill
flags. All 527 source arrays, shared scores and completion states match.
Empty browser diagnostics are the only new defaults removed; runtime-version,
receipt-numbering, cancellation-exit and fault-injection scheduling differences
remain explicit. Timings and job counts are retained without a speed claim.

The [browser evidence](../research/browser-release-hosts.json) verifies exact
artifact ZIP and member hashes for Chromium and Firefox on all five hosts:
52 proof cases per browser/host combination, including deadlines, cancellation,
crashes and no leftover processes or browser files. The
[workflow run](https://github.com/Binary-Balance/seshat/actions/runs/44669995327)
uses the same preparation head as the archive audit. These deliberate error
and timeout cases remain unresolved; their proof passing does not make them
kills or complete assessments.

Remaining preparation: five-host archive installation, latest-Vitest-5
verification, independent review and current-head checks, then the
reviewed-main publisher dry run before explicit publication approval.
No publication is claimed here.
