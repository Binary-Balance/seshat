# Seshat 0.19.0

Draft, unpublished. Release preparation is tracked in
[#312](https://github.com/Binary-Balance/seshat/issues/312); Alpine support is
tracked in [#125](https://github.com/Binary-Balance/seshat/issues/125).

## Alpine Linux

This release prepares native Alpine x64 and ARM64 packages. The entry package
selects glibc or musl from positive runtime evidence and reports an unsupported
platform when libc cannot be identified reliably. Consuming projects need no
Rust toolchain.

The verified candidate userspace is Alpine 3.24.2 on native x64/ARM64, with
Node `>=24.20.0 <25`. The minimum was checked using hash-pinned experimental
musl builds from Node's unofficial-builds project; these are not official
Node binary distributions. Linux `7.0.0-1017-azure` was observed in the installed
proofs. No older Alpine branch or minimum kernel is established.

The [prerequisite protocol](../alpine-prerequisites.md) and
[platform matrix](../platform-support.md) retain native CLI, npm/standalone,
Node, Vitest Node-mode, Jest/Expo, parallel-worker and lifecycle proofs.
They cover source preservation, deadlines, SIGINT/SIGTERM cancellation,
owned-descendant cleanup and scratch cleanup within the existing Unix
supervision limits. The experimental archives still use version 0.18.0;
they are prerequisite evidence, not the 0.19.0 release artifacts.

Rust 1.98.1 links its patched musl 1.2.5, LLVM libunwind and startup objects.
The [runtime audit](../research/alpine-runtime-notice-audit.md) records the
actual selected inputs and additional notices. Musl packages retain those
notices and portable linker-map evidence. The five existing native targets
retain their common runtime notice assets. External Cargo dependencies are
unchanged.

Vitest browser support remains limited to the five existing hosts: Linux
glibc x64/ARM64, macOS x64/ARM64 and Windows x64. Browser mode on Alpine is
unverified. Runner version ranges and report schema version 1 are unchanged.

## Planned package set

All eight packages must use exactly version 0.19.0:

- `@binary-balance/seshat`
- `@binary-balance/seshat-linux-x64`
- `@binary-balance/seshat-linux-arm64`
- `@binary-balance/seshat-linux-x64-musl`
- `@binary-balance/seshat-linux-arm64-musl`
- `@binary-balance/seshat-darwin-x64`
- `@binary-balance/seshat-darwin-arm64`
- `@binary-balance/seshat-win32-x64`

The publisher, release audit, local archive stager and registry verification
require this complete set from 0.19.0 onward, including prereleases. Historical
releases keep their six-package sets. The publisher sends the seven native
payloads before the entry package; the entry references their exact versions.

The published 0.18.0 audit is preserved unchanged as
[JSON](0.18.0-audit.json) and [Markdown](0.18.0-audit.md). The
[0.19.0 archive audit](../research/release-notice-audit.md) records eight exact
archives built from preparation head
`0996b5401b7ae9cbdb73f8062a317692e8a65711`, tested merge
`6c2e27796c094e2ac50fe5e2665cd39c55cb7bc1`, in
[PR #313](https://github.com/Binary-Balance/seshat/pull/313).
All seven native package proofs, Windows runtime and latest-supported-Node
checks passed. The audit verifies source trees, manifests, member modes,
archive/binary/notice hashes and musl runtime inputs, static linkage and retained
link maps. External dependency inventory, Rust toolchain and common runtime
notice assets match 0.18.0; musl packages add the audited musl notice payload.
The [seven-host installation matrix](https://github.com/Binary-Balance/seshat/actions/runs/45616431672)
passed at `0aca064d4f92b529c49fe0f81d8d08f761b4668c`. The
[independent verification](../research/alpine-release-install.json) checks all
seven ZIP digests, all 56 staged archives against the audit, installed native
and entry identities, lockfile integrities and 35 retained example results.
Worker parity and installed-tree checks rely on successful verifier assertions;
their raw worker-two JSON and installed project trees were not retained. The
report records these and the Alpine host-staging limits explicitly.

The [browser regression record](../research/alpine-release-browser.json)
verifies ten artifact ZIP identities and 520 retained case results: Chromium
and Firefox on all five existing hosts. The deliberate load-hang timeout counts
as a kill, while browser connection failures remain uncounted. Retained
observations show no owned processes or playwright-prefixed temporary entries;
the report preserves other remaining names, including `mozilla-temp-files`,
and the limits of those checks. Browser artifacts retain the CLI version but
not a binary digest. They do not establish Alpine browser support.

The prepared release merged in [PR #313](https://github.com/Binary-Balance/seshat/pull/313)
as `085187b39878785ca96236b56d8081e2e540ab1b`, with the same complete Git tree
as reviewed head `0aca064`. Fresh review had no actionable findings; 24 CI
checks succeeded and two were intentionally skipped. A Windows Firefox
cancellation sharing violation is tracked in
[#306](https://github.com/Binary-Balance/seshat/issues/306). Its unchanged
rerun passed all 52 cases, with no cancellation cleanup error and unchanged
scoring/cleanup guards. The [acceptance record](../research/alpine-release-acceptance.json)
retains the replacement artifact identity. The conflicting handle's cause
remains unknown.
