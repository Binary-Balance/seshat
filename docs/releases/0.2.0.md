# Seshat 0.2.0

This note records what changed between 0.1.0 and 0.2.0. Behaviour, package
layout and limits not listed here are unchanged from the
[0.1.0 release notes](0.1.0.md). The archive coordinates and native proof
results for this version are in the [current release audit](../research/release-notice-audit.md).

Report schema version 1 remains the public contract. The `toolVersion` value
is `0.2.0`.

Version 0.2.0 is published on npm from revision
[`f34d8f5`](https://github.com/Binary-Balance/seshat/commit/f34d8f5e02e61e5a9f4facce05fa79f32284cd7f).
Its [publication](https://github.com/Binary-Balance/seshat/actions/runs/37164667537),
[five-platform local install check](https://github.com/Binary-Balance/seshat/actions/runs/37124622802)
and [five-platform registry and provenance verification](https://github.com/Binary-Balance/seshat/actions/runs/37164942579)
passed.

## Wider runtime support

- Stable Node versions `>=24.20.0 <25` are accepted. Version 0.1.0 accepted
  only 24.20.0 ([#54](https://github.com/Binary-Balance/seshat/issues/54)).
- Stable Vitest versions `>=5.0.0 <6` are accepted. Version 0.1.0 accepted only
  5.0.0 ([#124](https://github.com/Binary-Balance/seshat/issues/124)).
- Jest 29.7.0 with jest-expo 57.0.5 is unchanged.

An unsupported version is reported with the actual version and the supported
range. The Node import-failure observer is verified only on Node 24.20.0 and
24.21.0. On other supported Node versions, an import crash that needs the
observer is reported as an execution error and leaves that mutant unresolved.
See the [runner compatibility guide](../runner-compatibility.md).

## Measurement fixes

- Coverage files with unsupported line separators are rejected. They could
  previously produce an inflated complete score
  ([#59](https://github.com/Binary-Balance/seshat/issues/59)).
- Empty callbacks with plain parameters are recognised as empty functions
  ([#60](https://github.com/Binary-Balance/seshat/issues/60)).
- Valid Istanbul mappings for labelled and `debugger` statements are accepted
  ([#61](https://github.com/Binary-Balance/seshat/issues/61),
  [#64](https://github.com/Binary-Balance/seshat/issues/64)).
- Load-failure evidence respects enclosing `catch` blocks
  ([#62](https://github.com/Binary-Balance/seshat/issues/62)).
- Experimental switching preserves hashbangs and directives
  ([#63](https://github.com/Binary-Balance/seshat/issues/63)).
- Malformed measured rows are rejected during threshold evaluation
  ([#75](https://github.com/Binary-Balance/seshat/issues/75)).

## Execution and cancellation

- The npm launcher preserves cancellation and returns the correct signal exit
  codes ([#57](https://github.com/Binary-Balance/seshat/issues/57)).
- Unix cleanup keeps ownership of the process group until it is reaped, closing
  a process ID reuse race
  ([#55](https://github.com/Binary-Balance/seshat/issues/55)).
- Job diagnostics are retained and cleanup waits are bounded
  ([#66](https://github.com/Binary-Balance/seshat/issues/66)).
- Windows spawning keeps the primary thread handle and cleans up after console
  helper failures ([#68](https://github.com/Binary-Balance/seshat/issues/68),
  [#69](https://github.com/Binary-Balance/seshat/issues/69)).
- Capture and source restoration guard against file and directory replacement
  during a run ([#70](https://github.com/Binary-Balance/seshat/issues/70)).
- Capture and mutation evidence growth is bounded
  ([#72](https://github.com/Binary-Balance/seshat/issues/72)).

## Stricter input checks

Some inputs that 0.1.0 accepted now fail before execution:

- Ambiguous captured path names
  ([#71](https://github.com/Binary-Balance/seshat/issues/71)).
- Missing assessment prerequisites, which are now checked before capture
  ([#73](https://github.com/Binary-Balance/seshat/issues/73)).

## CLI output

- Help text, path arguments and error output are clearer
  ([#74](https://github.com/Binary-Balance/seshat/issues/74)).
- A mutation timeout explains why the run stopped and why the score is
  withheld, with counts of mutants not run
  ([#53](https://github.com/Binary-Balance/seshat/issues/53)).

## Packages and documentation

The package set is unchanged: the entry package `@binary-balance/seshat@0.2.0`
and exact-version native payloads for Linux x64, Linux ARM64, macOS x64, macOS
ARM64 and Windows x64. The Linux payloads need glibc. Alpine Linux is not
supported; it is tracked in
[#125](https://github.com/Binary-Balance/seshat/issues/125).

Release builds clear ambient Rust flags, validate provenance before staging and
wait for native package availability before the entry package is published.
The GitHub and npm READMEs are shorter and share the same content.
